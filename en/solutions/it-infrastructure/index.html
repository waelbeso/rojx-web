OPERATING SCENARIO

Infrastructure sized for your applications

Operators reach the service through approved network segments. The server runs the application and reads its data from primary storage. A scheduled job writes a recoverable backup to the agreed destination. The team restores the service in an isolated environment, checks that it runs and verifies its data.

After the restore, open the application, check its data in the test environment and record the actual recovery time.

SYSTEM ARCHITECTURE

IT infrastructure components

A workstation connects to a protected application. IT tests recovery in a separate environment.

01

User endpoint

Runs the client used to access the application.

02

Access network

Connects wired and wireless devices to a network segment.

03

Core network

Routes traffic between approved network segments.

04

Firewall

Permits or denies connections according to policy.

05

Application server

Runs the service and accesses its data.

06

Primary storage

Holds the data used by the live application.

07

Backup service

Creates recoverable copies on a schedule.

08

Backup repository

Stores copies under separate access and retention rules.

09

Test environment

Hosts the restored copy for verification.

Optional fiber access: optical line terminal (OLT), passive optical splitter and optical network terminal (ONT).
PROJECT SCOPE

What the project includes

Core infrastructure
Access and core switches, network security boundaries, servers, storage and backup.
Optional optical network
An optical line terminal, passive splitters and optical network terminals at selected locations.
Site inputs
Application inventory, peak loads, network map, racks, power, cooling and recovery targets.
SITE PILOT

Pilot one business-critical application

  • Connectivity — Verify which paths are allowed and which are blocked between network segments.
  • Performance — Measure application performance under a load that reflects actual use.
  • Recovery — Restore a test copy, verify the data and record how long it takes to bring the service back.

Bring an application inventory, network diagram and service recovery priorities.

BEFORE THE SITE VISIT

Questions from the operations team

How do we verify that a backup can be restored?

Restore an agreed application in isolation, open it, verify its data and record the actual recovery time.

Is optical access required?

Optical access is optional. Site design determines whether to use an optical line terminal, passive splitters and optical network terminals.

What site information is needed to define the scope?

Application inventory, peak loads, network map, racks, power, cooling and recovery targets.
