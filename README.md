# ROJX — Smart Building & AI Solutions

موقع تعريفي بالعربية والإنجليزية، جاهز للنشر على GitHub Pages.

## تشغيل الموقع

افتح `index.html` في المتصفح. جميع التنسيقات والرسومات والبرمجة داخل الملف نفسه، دون مكتبات خارجية أو تثبيت أو خطوة بناء. خط Cairo العربي مدمج داخل HTML بصيغة WOFF، ويعمل دون تحميل الخط من خدمة خارجية. ترخيص SIL Open Font License مرفق داخل الملف وفي FONT-LICENSE.txt.

## النشر على GitHub Pages

1. أنشئ مستودعًا باسم `rojx-website` في حسابك. استخدام مستودع عام مناسب لخطة GitHub Free.
2. ارفع **محتويات** هذه الحزمة في جذر المستودع؛ يجب أن يكون `index.html` في الجذر، لا داخل مجلد إضافي. فك ضغط ZIP أولًا؛ رفع ZIP وحده لا ينشر الموقع.
3. افتح **Settings → Pages → Build and deployment**.
4. اختر **Deploy from a branch** ثم الفرع **main** والمجلد **/ (root)** واضغط **Save**.
5. بعد انتهاء النشر، افتح رابط الموقع الذي يعرضه GitHub. يعمل الموقع أيضًا تحت مسار مستودع فرعي.

## ربط rojx.com

نفّذ الربط بعد ظهور الموقع بنجاح على عنوان GitHub Pages. لم يتم تعديل أي DNS أو نشر الموقع من هذه الحزمة تلقائيًا.

1. من **Settings → Pages → Custom domain** أدخل `rojx.com` واحفظ. عند النشر من فرع، ينشئ GitHub ملف `CNAME` تلقائيًا. يوجد `CNAME.example` في الحزمة كمثال؛ لا يلزم نشره ولا إعادة تسميته قبل إعداد الدومين.
2. لدى مزود الدومين، جهّز سجلات `A` التالية للمضيف `@`:

| النوع | الاسم | القيمة |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |

3. اختياريًا، أضف `CNAME` للمضيف `www` بالقيمة `YOUR-USERNAME.github.io`؛ استبدل YOUR-USERNAME باسم حسابك الفعلي، دون https أو اسم المستودع.
4. راجع سجلات الموقع الحالية قبل تغييرها، وأزل التعارض فقط. احتفظ بسجلات البريد `MX` و`TXT` وغيرها من الخدمات غير المرتبطة باستضافة الويب.
5. انتظر فحص DNS وإصدار الشهادة، ثم فعّل **Enforce HTTPS** عندما يصبح الخيار متاحًا. قد يستغرق انتشار DNS حتى 24 ساعة.
6. يُفضّل التحقق من ملكية الدومين من إعدادات حساب GitHub → Pages باستخدام سجل TXT الذي يعطيه GitHub.

المراجع الرسمية (تمت مراجعتها 28 أكتوبر 2026):

## التواصل والتعديل

- رقم الاتصال وواتساب: `+20 100 586 6678`، بناء على الرقم الذي قدمه المالك.
- لتغيير الرقم، ابحث داخل `index.html` عن `201005866678` و `+20 100 586 6678` واستبدلهما.
- النموذج يكوّن رسالة واتساب مشفرة في الرابط؛ العميل يراجعها ويرسلها بنفسه. لا توجد قاعدة بيانات أو رسائل بريد من الخادم أو لوحة إدارة.
- اللغة مرتبطة بعنوان الصفحة؛ لا يوجد توجيه تلقائي أو حفظ لتفضيلها. لا تُحفظ حقول النموذج، ولا توجد تحليلات زيارات أو متتبعات مضافة.
- النصوص الثابتة موجودة في `data-ar` و`data-en`، ومحتوى تبويبات الحلول في مصفوفة `solutions` داخل السكربت.
- الألوان في متغيرات `:root` داخل CSS. الرسم المعماري SVG أصلي ومدمج وقابل للتعديل.
- العربية في `/index.html` والإنجليزية في `/en/index.html`؛ كل لغة لها HTML مستقل وروابط hreflang وcanonical. ارفع مجلد en بالكامل. ملف HTML المنفرد للمعاينة المحلية، أما النشر فيحتاج الحزمة كاملة.

## نطاق المحتوى

استُخدم الملف المرفق `02-Inspur Smart Building Solution-202405.pdf` كمرجع لمجالات الحلول: المواقف، دخول الأشخاص والمركبات، الزوار، الشبكات، قاعات الاجتماعات، المراقبة ومركز العمليات. لم تُنسخ مخططات مشروعه أو كميات أجهزته، ولم يتم تضمين ملفه في الموقع المنشور.

قسم BMS / IBMS والطاقة والـAI إضافة إلى نطاق العرض استنادًا إلى طلب تقديم حلول المباني الذكية والمدعومة بالذكاء الاصطناعي، وليس ادعاءً بأن الملف المرفق يقدم تلك القدرات بالتفصيل. التطبيقات مشروطة بالتقييم الفني والبيانات والتوافق.

لا توجد ادعاءات بشراكة مع Inspur أو Huawei، أو شهادات أو عملاء أو مشروعات سابقة أو نسب توفير مثبتة. راجع توافق نطاق الخدمات المقترح مع الخدمات التي تقدمها ROJX فعليًا قبل الاستخدام التجاري.
